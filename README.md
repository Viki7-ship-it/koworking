## О проекте

Telegram-бот для бронирования рабочих мест в коворкинге **общежития №15 РУДН**.  
Пилотная версия системы, которая в перспективе охватит все коворкинги кампуса и будет интегрирована в официальное приложение РУДН.

**Проблема:** Студенты не могут заранее узнать о свободных местах и гарантировать места для групповой работы.

**Решение:** Telegram-бот с верификацией студентов, групповым бронированием и административным разделом.

---

## Возможности

### Для студентов
- Регистрация и верификация по номеру студенческого билета РУДН
- Просмотр свободных мест по датам и временным слотам
- Одиночное и групповое бронирование (от 1 до 6 мест)
- Просмотр своих активных бронирований
- Отмена брони в один клик
- Справка `/info` с описанием работы бота

### Для администратора
- Подтверждение или отклонение заявок на верификацию
- Подробная статистика `/stats`: брони по датам, слотам и студентам

## Установка и запуск

### 1. Требования
- Python 3.10+
- pip

### 2. Установка зависимостей

```bash
pip install aiogram aiosqlite
```

### 3. Настройка

Откройте `bot.py` и укажите:

```python
TOKEN = "ВАШ_ТОКЕН_ОТ_BOTFATHER"   # токен от @BotFather
ADMIN_IDS = [ВАШ_TELEGRAM_ID]       # узнать свой ID: @userinfobot
```

### 4. Запуск

```bash
python bot.py
```

После запуска в консоли появится сообщение **«Бот запущен»**.  
Найдите бота в Telegram по имени пользователя и отправьте `/start`.
